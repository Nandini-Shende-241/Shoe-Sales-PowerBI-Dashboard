# Shoe Sales Analysis Dashboard

A Power BI-based interactive sales dashboard designed to analyze shoe sales performance, customer behavior, transaction patterns, and product trends through clear and interactive visualizations.

## Project Overview

This project presents an interactive Power BI dashboard created from shoe sales data. The dashboard transforms raw sales data into meaningful business insights using KPI cards, charts, a map visualization, and interactive slicers.

The dashboard helps analyze overall sales performance, product performance, customer ratings, payment methods, and sales trends across different time periods and categories.

## Key Features

- Interactive Power BI sales dashboard
- Total Sales KPI
- Total Quantity KPI
- Transactions KPI
- Average Sales KPI
- Total Sales by City analysis
- Total Quantity by Month analysis
- Customer Ratings analysis
- Transactions by Payment Method
- Total Sales by Shoe Type
- Total Sales by Day Name
- Brand-wise sales and quantity analysis
- Interactive filtering using slicers
- Analysis by Shoe Type, Payment Method, Brand, Day Name, Gender, and Month
- Executive-style dashboard design

## Key Insights

- Overall sales performance can be monitored through KPI cards.
- Monthly quantity trends help identify changes in sales volume over time.
- City-level analysis provides a geographical view of sales performance.
- Payment-method analysis shows transaction distribution across different payment types.
- Shoe-type and brand analysis helps compare product performance.
- Customer ratings provide insights into customer satisfaction.
- Day-wise analysis helps identify sales patterns across different days.
