👟 Shoe Sales Dashboard

A Power BI data analytics dashboard designed to analyze shoe sales data and provide meaningful insights into sales performance, profitability, quantity sold, and business trends.

📌 Project Overview

The Shoe Sales Dashboard transforms raw sales data into an interactive and visually appealing dashboard using Microsoft Power BI.

The dashboard helps analyze important business metrics and identify sales trends through interactive charts, cards, filters, and visualizations.

It provides a clear overview of sales performance and helps users understand business performance from different perspectives.

✨ Key Features

- 📊 Interactive sales dashboard
- 💰 Total Sales analysis
- 📈 Profit analysis
- 📦 Quantity sold analysis
- 📅 Year-wise sales analysis
- 🔍 Interactive filters and slicers
- 📊 Sales trend visualization
- 📉 Profitability analysis
- 🎯 Business performance insights
- 🖥️ Interactive Power BI visuals
